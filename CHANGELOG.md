# Changelog

All notable changes to **SpiderWeb** are documented in this file.

## [1.0.0] - 2026-10-18

### Added
- **4-Stage Developer Kanban Board:** `To Do`, `In Progress (Doing)`, `In Review (for Code)`, and `Done` columns with drag-and-drop and 1-click stage transitions.
- **Standalone Native GTK4/Wayland Desktop Executable (`./spiderweb`):** Embedded single-file binary requiring zero local servers or external browsers.
- **Collapsible Sidebar & Icon-Only Dock:** Zero-scroll full sidebar that collapses into a `68px` icon-only dock via `[` or `Ctrl + B`.
- **Up Next & My Tasks Views:** Dedicated high-velocity focus queues sorted by deadline urgency.
- **Real-Time Analytics & Velocity Charts:** SVG completion ring, pipeline distribution bar, per-project progress bars, and a Due Time Countdown Radar.
- **Project Management:** Create projects with custom accent colors, workspace tags, due dates, and safe project removal modals.
- **Keyboard-First Experience:** Built-in `Ctrl + K` Command Palette, `?` Keybinds Showcase modal, and instant Light/Dark mode toggle (`T`).
- **Custom Sharp Black Spider Icon:** Vector logo integrated across the native app and `.desktop` launcher.
